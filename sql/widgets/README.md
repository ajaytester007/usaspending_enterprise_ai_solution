# Dashboard Widget SQL Notes

This folder is reserved for widget-specific SQL extracts where a widget query differs from the reusable semantic dataset.

Recommended naming:

```text
<page>_<widget_name>.sql
```

Examples:

```text
executive_overview_kpi_total_obligations.sql
advanced_analytics_volume_vs_value.sql
geography_drilldown_geo_readiness_table.sql
```
